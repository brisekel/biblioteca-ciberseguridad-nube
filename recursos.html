🧠 Glosario Básico

Cloud Computing

Modelo de acceso a recursos tecnológicos a través de Internet.

Virtualización

Tecnología que permite crear recursos virtuales a partir de infraestructura física.

Workload

Conjunto de recursos utilizados para ejecutar una aplicación.

Serverless

Modelo que permite ejecutar aplicaciones sin gestionar directamente servidores.
